# Self Pause 開発計画

## Phase 1: 最小プロトタイプ

1. 画面の基本レイアウトを作成
2. `LOCKED` / `UNLOCKED`の状態管理を実装
3. 初回起動時の10秒解禁カウントダウンを実装
4. `visibilitychange`による復帰検知を実装
5. 終了カウントダウンを実装
6. 鉄の扉の開閉をCSSアニメーションで表現
7. ゲーム機アイコンの封印・解除を表現

## Phase 2: 履歴機能

1. activeSessionを実装
2. 使用可能状態への移行時刻を記録
3. 使用禁止状態への移行時刻を記録
4. 活動内容選択UIを実装
5. 履歴保存を実装
6. 1年経過データの自動削除を実装
7. 履歴一覧画面を実装
8. 個別削除・一括削除を実装

## Phase 3: 活動項目管理

1. 固定項目を登録
2. ユーザー独自項目の追加
3. 項目編集
4. 項目削除
5. 履歴の活動名スナップショット対応

## Phase 4: 品質向上

1. スマートフォン表示の最適化
2. `prefers-reduced-motion`対応
3. localStorage破損時の処理
4. ブラウザ戻る操作のテスト
5. バックグラウンド・復帰のテスト
6. 画面遷移・状態遷移のテスト
7. 操作説明とデータ消失に関する注意書きの追加

## 推奨テストケース

- 初回起動で10秒後にUNLOCKEDになる
- カウントダウン中にhiddenになり、復帰時に10秒からやり直す
- UNLOCKED中の復帰でLOCK_COUNTDOWNになる
- LOCK_COUNTDOWN完了後にLOCKEDになる
- LOCKED中の復帰でUNLOCK_COUNTDOWNになる
- 戻る操作でカウントダウンが中断され、状態が変化しない
- 活動履歴の開始時刻・終了時刻・継続時間が正しい
- 活動項目を削除しても過去の履歴が表示できる
- 365日を超えた履歴が削除される
- 個別削除・一括削除が機能する
- localStorageが空または壊れていても初期化できる
- reduced-motion設定時に過剰なアニメーションが発生しない
