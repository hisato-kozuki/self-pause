# Self Pause 要件定義書

## 1. サービス概要

| 項目 | 内容 |
|---|---|
| サービス名 | Self Pause |
| 読み方 | セルフポーズ |
| 形態 | スマートフォン向けWebアプリ |
| 対象 | ゲーム・テレビなどを自分でやめることが難しい小中学生・大人 |
| 目的 | 活動の開始・終了に向けた心理的な準備を支援する |
| 強制制限 | 行わない |
| 使用時間制限 | 行わない |
| アカウント | 初期版では実装しない |
| 対応端末 | 原則として1台の端末 |
| 保存先 | localStorage |
| 履歴保存期間 | 1年間 |

## 2. 用語定義

### 使用可能状態

ユーザーが対象活動を開始できる状態。アプリは活動の利用可否を技術的には制限しない。

### 使用禁止状態

ユーザーが対象活動を終了し、次の活動へ移行することを目指す状態。アプリがゲーム等を強制的に停止するわけではない。

### 解禁カウントダウン

使用禁止状態から使用可能状態へ移行するための10秒間のカウントダウン。

### 終了カウントダウン

使用可能状態から使用禁止状態へ移行するための10秒間のカウントダウン。

### 活動履歴

使用可能状態から使用禁止状態へ移行するまでの時間と、終了後に選択した直前の活動内容を記録したデータ。

## 3. 機能要件

### FR-001 初回起動

- 初回起動時の論理状態は使用禁止状態とする。
- 初回起動時は、使用可能状態へ移行する解禁カウントダウンを自動開始する。
- ユーザーによる開始ボタン・確認ボタンの操作は要求しない。
- カウントダウン完了後、使用可能状態へ移行する。

### FR-002 状態切り替え

- 使用禁止状態でアプリが前面に復帰した場合、解禁カウントダウンを開始する。
- 使用可能状態でアプリが前面に復帰した場合、終了カウントダウンを開始する。
- カウントダウン完了時に、反対側の状態へ移行する。
- カウントダウン中にバックグラウンドへ移行した場合、カウントダウンを中断する。
- 次回復帰時は10秒からやり直す。
- 完全再起動時もlocalStorageに保存された前回状態を基準に動作する。

### FR-003 戻る操作

- カウントダウン中にブラウザの戻る操作が行われた場合、カウントダウンを中断する。
- この場合、状態を変更しない。
- 次回アプリが前面に復帰した際に、10秒からカウントダウンを開始する。

### FR-004 解禁カウントダウン画面

- 画面上部に残り時間ディスプレイを表示する。
- 画面中央では、手前に鉄の扉を配置する。
- 残り時間・ゲーム機アイコン・必要な表示は扉の奥に見える構成とする。
- ゲーム機アイコンは鎖で封印された状態から開始する。
- 10秒経過時に封印解除アニメーションを再生する。
- メッセージウィンドウを画面下部に表示する。

### FR-005 終了カウントダウン画面

- 画面上部に残り時間ディスプレイを表示する。
- 画面中央では、手前に鉄の扉を配置する。
- ゲーム機アイコンは封印されていない状態から開始する。
- 10秒経過時にゲーム機を鎖で封印するアニメーションを再生する。
- メッセージウィンドウを画面下部に表示する。

### FR-006 使用可能状態画面

- 封印が解除されたゲーム機アイコンを表示する。
- 使用可能状態であることを表示する。
- 活動経過時間は画面には表示しない。
- 活動経過時間は内部で計測する。

### FR-007 使用禁止状態画面

- 封印されたゲーム機アイコンを表示する。
- 使用禁止状態であることを表示する。
- 直前の活動内容を選択するUIを表示する。
- 活動内容選択後、活動履歴を確定する。

### FR-008 活動内容管理

- 固定項目を用意する。
- ユーザー独自の活動項目を追加できる。
- 活動項目を編集できる。
- 活動項目を削除できる。
- 使用中または履歴から参照されている項目を削除する場合の扱いを別途実装上定義する。推奨は、履歴表示用の名称を保持し、論理削除または削除確認を行う方式。

### FR-009 活動履歴

- 使用可能状態への移行時刻を活動開始時刻として仮記録する。
- 使用禁止状態への移行時刻を活動終了時刻として記録する。
- 使用禁止状態へ移行した直後に選択された活動内容を履歴に紐付ける。
- 活動時間を秒単位で保存する。
- 履歴は日付ごとの一覧で表示する。
- 将来的な拡張としてカレンダー表示・グラフ表示・活動別集計を想定する。

### FR-010 履歴削除

- 履歴を個別に削除できる。
- 履歴を一括削除できる。
- 一括削除には確認ダイアログを表示する。
- 保存期間を超えた履歴は自動削除する。
- 保存期間は1年間とする。

## 4. 非機能要件

### NFR-001 操作性

- スマートフォンの片手操作を考慮する。
- カウントダウン中に追加操作を要求しない。
- 文字と残り時間は視認性を確保する。
- タップ領域は十分な大きさを確保する。

### NFR-002 デザイン

- SF要素は控えめにする。
- シンプルで落ち着いた画面構成とする。
- 鉄の扉は画面手前に置く。
- 残り時間、ゲーム機アイコン、メッセージウィンドウは扉の奥に隠れるように見せる。
- 重厚感は維持するが、過度な発光・装飾は避ける。

### NFR-003 データ

- 端末内に保存する。
- サーバーへの送信は行わない。
- データ破損時にアプリが停止しないようにする。

### NFR-004 アクセシビリティ

- `prefers-reduced-motion`に対応する。
- 色だけに依存せず、文字やアイコンでも状態を伝える。
- コントラストを確保する。

## 5. 初期版の対象外

- ゲームやテレビの強制停止
- 使用時間の上限設定
- アカウント・ログイン
- 複数端末間の同期
- 保護者による遠隔管理
- クラウドバックアップ
- 通知・プッシュ通知
