# Self Pause 状態遷移仕様書

## 1. 論理状態

- `LOCKED`: 使用禁止状態
- `UNLOCKED`: 使用可能状態
- `UNLOCK_COUNTDOWN`: 使用禁止状態から使用可能状態へ移行中
- `LOCK_COUNTDOWN`: 使用可能状態から使用禁止状態へ移行中
- `ACTIVITY_SELECTION`: 使用禁止状態への移行後、直前の活動内容を選択中

## 2. 初回起動

```text
未初期化
  ↓
LOCKEDを保存
  ↓
UNLOCK_COUNTDOWNを開始（10秒）
  ↓ 10秒完了
UNLOCKEDへ遷移
```

## 3. 通常の状態遷移

```text
UNLOCKED
  │ アプリが前面に復帰
  ▼
LOCK_COUNTDOWN
  │ 10秒完了
  ▼
LOCKED
  │ 活動内容を選択
  ▼
履歴を確定
  │ アプリが前面に復帰
  ▼
UNLOCK_COUNTDOWN
  │ 10秒完了
  ▼
UNLOCKED
```

## 4. 中断ルール

### バックグラウンド移行

- カウントダウン中に`hidden`になった場合、カウントダウンを破棄する。
- 状態はカウントダウン開始前の状態のまま保持する。
- 次回`visible`時に10秒から再開する。

### ブラウザの戻る操作

- カウントダウン中の戻る操作では、カウントダウンを破棄する。
- 状態は変更しない。
- 次回復帰時に10秒から再開する。

### 再起動

- localStorageから最後に確定した論理状態を読み込む。
- `LOCKED`なら解禁カウントダウンを開始する。
- `UNLOCKED`なら終了カウントダウンを開始する。
- カウントダウン途中の状態は永続化しない。

## 5. 状態確定の原則

- 10秒のカウントダウン完了前に状態を変更しない。
- アニメーションの途中で履歴を確定しない。
- 終了カウントダウン完了後、終了時刻を記録する。
- その後、直前の活動内容を選択して履歴を確定する。
- 活動内容が選択されるまで、未確定履歴として保存してもよい。

## 6. 活動時間の扱い

- 使用開始時刻: `UNLOCKED`への移行完了時刻
- 使用終了時刻: `LOCKED`への移行完了時刻
- 使用時間: 使用終了時刻 - 使用開始時刻
- 活動内容: 使用禁止状態への移行後に選択された直前の活動
