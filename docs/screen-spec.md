# Self Pause 画面仕様書

## 1. 画面一覧

| ID | 画面名 | 役割 |
|---|---|---|
| SCR-001 | 解禁カウントダウン画面 | 使用可能状態への移行 |
| SCR-002 | 使用可能状態画面 | 使用可能状態の表示 |
| SCR-003 | 終了カウントダウン画面 | 使用禁止状態への移行 |
| SCR-004 | 使用禁止状態画面 | 封印状態の表示・直前の活動選択 |
| SCR-005 | 活動履歴画面 | 履歴の一覧表示・削除 |
| SCR-006 | 活動内容管理画面 | 活動項目の追加・編集・削除 |
| SCR-007 | 活動内容編集ダイアログ | 活動項目の作成・編集 |

## 2. 共通レイアウト

### 2.1 カウントダウン画面

上から順に次の構成とする。

1. ヘッダーまたは残り時間ディスプレイ
2. 画面中央の扉演出領域
3. 画面下部のメッセージウィンドウ

重要な視覚構成:

- 鉄の扉を画面の手前に置く。
- 扉の奥に、残り時間表示・ゲーム機アイコン・メッセージウィンドウが存在するように見せる。
- 扉が開くことで、奥の要素が見える。
- 解禁時はゲーム機が鎖で封印されている。
- 終了時はゲーム機が解放されている。
- カウントダウン完了時に、封印解除または封印のアニメーションを行う。

## 3. SCR-001 解禁カウントダウン画面

### 表示

- 残り時間: 10から0まで
- 扉: 手前に閉じた状態で表示し、開くアニメーションを再生
- ゲーム機: 扉の奥にあり、鎖で封印されている
- メッセージ例: 「ゲームを始める準備をしましょう」

### 完了時

- 封印解除アニメーション
- 使用可能状態へ遷移
- SCR-002を表示

## 4. SCR-002 使用可能状態画面

### 表示

- 使用可能状態のラベル
- 扉の奥にある、封印解除済みのゲーム機アイコン
- メッセージウィンドウ
- 活動経過時間は表示しない

### 操作

- 基本的に追加操作は不要
- 履歴画面・設定画面への導線は、画面端の控えめなナビゲーションとして配置可能

## 5. SCR-003 終了カウントダウン画面

### 表示

- 残り時間: 10から0まで
- 扉: 手前に閉じた状態で表示し、開くアニメーションを再生
- ゲーム機: 封印されていない状態
- メッセージ例: 「ゲームを終える準備をしましょう」

### 完了時

- 鎖による封印アニメーション
- 使用禁止状態へ遷移
- SCR-004を表示

## 6. SCR-004 使用禁止状態画面

### 表示

- 封印されたゲーム機アイコン
- 使用禁止状態のラベル
- 直前の活動内容を選択するボタン群
- 例: ゲーム、テレビ、動画視聴、SNS、その他、ユーザー追加項目

### 活動選択後

- 直前の活動内容を履歴に紐付ける
- 保存完了を通知する
- 活動選択済み状態を表示する

## 7. SCR-005 活動履歴画面

### 基本表示

日付ごとの一覧表示とする。

| 日付 | 活動内容 | 使用時間 |
|---|---|---|
| 2026/09/21 | ゲーム | 45分 |
| 2026/09/21 | テレビ | 30分 |

### 機能

- 年月の切り替え
- 一覧表示
- 個別削除
- 全履歴削除
- 1年以上経過した履歴の自動削除

### 将来拡張

- カレンダー表示
- グラフ表示
- 活動内容ごとの集計

## 8. SCR-006 活動内容管理画面

### 機能

- 固定項目一覧
- ユーザー定義項目一覧
- 項目の追加
- 項目名の編集
- 項目の削除

### 注意

履歴が参照している活動項目を削除しても、過去の履歴が読めなくならないようにする。
履歴には活動IDだけでなく、保存時点の活動名スナップショットを保持することを推奨する。

## 9. ナビゲーション

初期版では、次のナビゲーションを想定する。

- ホーム
- 履歴
- 活動内容管理

カウントダウン中は、誤操作を避けるため、主要なナビゲーションを制限してもよい。
ただし、ブラウザの戻る操作を完全に制御できるとは限らないため、状態確定は必ずカウントダウン完了時に行う。
