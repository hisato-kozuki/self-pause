# Self Pause

ゲーム・テレビ視聴などの開始・終了に10秒間の準備時間を挟むことで、活動の切り替えを支援するスマートフォン向けWebアプリ。詳しい狙いは `CLAUDE.md` を参照。

## ファイル構成

- `index.html` / `css/style.css` / `js/*.js`: 実装（サーバー不要、`docs/`の要件定義に基づく初期版）
- `CLAUDE.md`: Claude Code向けの開発方針・完成条件
- `docs/requirements.md`: 要件定義書
- `docs/screen-spec.md`: 画面仕様書
- `docs/state-machine.md`: 状態遷移仕様書
- `docs/data-design.md`: localStorageデータ設計（カレンダー連動プログラムとの互換フィールドについての実装メモを含む）
- `docs/development-plan.md`: 開発計画・テスト項目

## 動かし方

ビルド不要の静的サイトなので、このフォルダを任意の静的サーバーで配信するだけで動く。

```bash
cd self-pause-spec
python -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

`file://`で直接`index.html`を開いてもES Modulesが動くブラウザなら概ね動作するが、
ローカルサーバー経由での確認を推奨する。

## 実装済みの範囲

`docs/development-plan.md`のPhase 1〜3に相当する機能を実装済み。

- LOCKED/UNLOCKEDの状態管理と、解禁・終了それぞれ10秒のカウントダウン
- `visibilitychange`によるバックグラウンド中断・前面復帰時の再カウントダウン
- ブラウザの戻る操作（サブ画面からの`popstate`）でのカウントダウン中断
- 鉄の扉の開閉・鎖の封印/解除をCSSアニメーションで表現（`prefers-reduced-motion`対応）
- 活動履歴の記録・月単位の一覧表示・個別削除・月単位の一括削除・1年経過分の自動削除
- 活動項目の追加・編集・削除（論理削除。削除後も過去履歴の表示名は保持）
- localStorage破損・容量不足時のフォールバックと警告表示

## 実装上の判断（仕様のあいまいな点への対応）

`docs/state-machine.md`は、終了カウントダウン完了後に「活動内容を選択」してから
「アプリが前面に復帰した場合、解禁カウントダウンを開始する」という通常ルールへ戻る、
という順序を想定しているが、直前の活動が未選択のままアプリを再起動した場合の扱いは
明記されていなかった。本実装では、未選択の記録（`pendingHistory`）が残っている間は
解禁カウントダウンを開始せず、使用禁止状態画面（活動選択UI）を優先して表示するようにした。
これにより、直前の活動を選ばないまま次のセッションが始まってしまうことを防いでいる。
